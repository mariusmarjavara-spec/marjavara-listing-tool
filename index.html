Marjavara Listing Manager

A private tool that keeps the listings of one Etsy shop accurate. It reads the shop's own listings, and updates their title, description and tags only after the shop owner has approved each change.

What it does

  • Reads the listings of the shop owner's own Etsy shop.
  • Compares each listing with the approved product description kept by the shop owner, and reports where they differ.
  • Updates the title, description and tags of an existing listing, one change at a time, and only after the owner has approved that exact change.
  • Reads the listing back from Etsy afterwards to confirm the change is what Etsy now shows.

What it does not do

  • It does not create, publish, relist or renew listings, and it never changes a listing's state.
  • It does not change prices, images, inventory or the files buyers receive.
  • It does not read orders, receipts, messages or any buyer information.
  • It talks to Etsy only through the official Etsy Open API, and it is not offered to other sellers.
  • It does not show advertising, and it does not sell, share or resell any data.

Who uses it

One person: the owner of the shop it is connected to, working on that shop's own listings. It is not a public service and has no accounts for other people.

Etsy access it asks for, and why

listings_rTo read the shop's listings so they can be compared with the approved description and checked after an update.
listings_wTo update the title, description and tags of an existing listing, after the owner has approved that change.
shops_rTo find the shop that belongs to the connected account.

How changes are controlled

Every write to Etsy needs a separate, single-use approval from the shop owner that names the exact listing and the exact content. If the content changes after approval, the approval no longer applies. If Etsy does not answer, or the result is unclear, the tool stops and checks the listing before doing anything else, so a listing is never created twice or changed twice by mistake.

Privacy

  • The tool runs on the shop owner's own computer. There is no server operated for it and no database of users.
  • The Etsy access token is stored in a file on that computer, readable only by its owner, and is never sent anywhere except to Etsy.
  • The tool does not collect or store buyer personal data, because it never requests it.
  • This website has no cookies, no analytics, no forms and no scripts.
